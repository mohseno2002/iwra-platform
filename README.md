# منصة مصلحة الري الرقمية — v2.5.0 (PWA)

مركز قيادة هيدروليكي موحّد بملف واحد: توأم النيل، معمل هيدروليكي (مانينج/GVF-RK4)، بوابات وهدارات، معايرة Q–H، مناوبات واحتياجات، آبار، سجلات تشغيلية، غرفة أزمات، تقرير موقف يومي، **وملخصات حية** من التوائم الرقمية عبر Firebase REST وGoogle Sheets.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثال: `iwra-platform`).
2. ارفع محتويات هذا المجلد كما هي (index.html، sw.js، manifest.webmanifest، مجلد icons، .nojekyll).
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main / (root)** ← Save.
4. الرابط: `https://mohseno2002.github.io/iwra-platform/`

من Termux بدلًا من الموقع:
```
git init && git add . && git commit -m "IWRA Platform v2.5.0"
git branch -M main
git remote add origin https://github.com/mohseno2002/iwra-platform.git
git push -u origin main
```

## التثبيت على الأجهزة
- **أندرويد (Chrome):** افتح رابط Pages ← سيظهر زر **«📲 تثبيت»** أعلى المنصة، أو من قائمة ⋮ ← «تثبيت التطبيق».
- **آيفون/آيباد (Safari):** زر المشاركة ⬆︎ ← «إضافة إلى الشاشة الرئيسية».
- **ويندوز/ماك (Chrome/Edge):** أيقونة التثبيت في شريط العنوان أو زر «📲 تثبيت» داخل المنصة.

بعد التثبيت يعمل التطبيق **دون اتصال** (تُحفظ القشرة كاملة)، وتظل الملخصات الحية تعرض آخر قيم مخزّنة مع تنبيه عند تعذر المزامنة.

## تحديث نسخة منشورة
عدّل `index.html` ثم غيّر رقم الإصدار في أول سطر من `sw.js` (`var V='iwra-v…'`) وارفع الملفين — الأجهزة تلتقط التحديث في الفتح التالي.

## المزامنة الحية
- القاعدة الافتراضية: `ismailia-64500` (europe-west1) — قابلة للتغيير من «بوابة تطبيقاتي».
- اسمح بالقراءة العامة في قواعد أمان Firebase على مسارات القراءات/exports فقط.
- عامل الخدمة **لا يعترض** طلبات Firebase أو Google Sheets (بيانات حية دائمًا).

اختبارات الجودة: 66 فحصًا آليًا (محرك + تشغيل + مزامنة) — جميعها ناجحة.
